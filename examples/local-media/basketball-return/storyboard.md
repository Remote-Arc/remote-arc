# 《回弹》 / The Return — 60-second original pilot

一口气的论点：篮球把下落的运动暂存在球壳与压缩空气里，再释放成回弹；热、声等损耗使它每次跳得更低，运球的手继续补能。

这支样片按用户指定做 60 秒、1920×1080/30fps、无旁白、指定 BGM。采用 vibe-knowledge-film 的 C 夜曲方法；全部画面为这个主题现写，不搬示例内容。中英各输出一版，语言不混排。

锚：一颗有正确球面缝线和材质的篮球、一段木球场、同一把高度尺。镜头从球场推到压缩球体和内部，再退出；最后回到开场。橙色=篮球，冰蓝=空气/回复运动，玫红=耗散，暖白=文字。数字示意不当作实测数据。
